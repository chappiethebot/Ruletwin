# RuleTwin — method note

**Rental Housing Law Navigator · v5 participant release · isolated verified snapshot `snap-eea786560def` (integration pending) · as of 2026-10-01. Legal information, not legal advice; not reviewed by counsel.**

**What it does.** For each of the 500 sample addresses, RuleTwin reports which rental-housing rules apply on a chosen date: in force, superseded by a local rule, not yet effective, pending or unknown. Every answer carries its citation, source document, retrieval date and as-of date. It also reports the addresses affected by the five supplied change tests (T1–T5).

**Module A — automated extraction.** Available text goes to an LLM (Claude Sonnet via structured output, one call per document chunk, cached). It returns jurisdiction, category, lifecycle/date, requirement (English and Spanish), key value, penalty, citation, a headline quote and allowlisted coverage predicates. Every exported headline quote must match its source character-for-character. Records are consolidated automatically; submission rule records are not hand-written. The 87 distributed entries plus two research captures have 89 dispositions (47 with rules, 9 with no in-scope rule, 33 link-only), with zero extraction errors. Result: 48 rules, 45 nonempty key values and 17 nonempty penalties. Condition/exemption field provenance and provision recall remain incomplete.

**Module B — address lookup.** The legal city comes from the US Census Geocoder (incorporated place, county). A match is accepted only if it carries the input's house number. Postal city is never trusted. Remaining identity gaps use official public evidence: municipal assessor rolls, the Census ZIP–place relationship file with MassGIS street corroboration, and the NJ geocoder plus municipal boundaries. One address (A0346) stays ambiguous and reports only conclusions shared by both candidate cities. A single deterministic TypeScript engine, shared by the website and the exports, evaluates each rule with true/false/unknown logic over building facts, dates and local-versus-state precedence. Where facts are missing, constraint reasoning checks every admissible value. It proves answers that cannot change, and otherwise returns the outcome for each value and the one decisive question. Year built is not a certificate-of-occupancy date: a cutoff inside the build year stays unknown. Owner facts are never inferred.

**Module C — change tracking.** Every case is evaluated through the same dated path as address reports. T1: 250 California addresses go from not yet effective to applies. T2: 90 addresses, Hoboken and Jersey City only, none in Newark. T3: 140 NJ addresses, with 90 flagged for a possible conflict with the local bans. T4: both MA bills stay pending; 110 addresses would be affected if enacted, evaluated as a labelled hypothetical. T5: empty set, since a struck ballot question never becomes law.

**Results.** Lookups: 3,373 applies, 289 superseded, 140 not yet effective, 440 pending, 511 unknown. The unknowns fall on 207 properties, averaging 1.8 decisive questions each.

**Honest limits.** Three rules quote research captures S037/S059 corresponding to link-only D037/D059. They are exported under the manifest IDs D037/D059 with `source_in_supplied_corpus: false`; they earn no citation credit. Eligibility requires distributed text, URL/identity agreement and exact headline offsets; it does not establish full rule entailment. Berkeley's algorithmic-ban date (2026-01) appears only in the research capture, so all 40 Berkeley answers for it are flagged for human review (guide §9). Santa Ana NS-3090, Hoboken rent control and Newark rent control lack supplied text. CO within the build year, affordability and untestable exemption defaults are disclosed presumptions. Strict exemptions removes only that exemption shortcut. Historical versions and full effect schedules remain incomplete; reference cases C35/C37 need source-backed adjudication.

**Validation and reproducibility.** The isolated repair passes 55 tests and 16 browser journeys, typecheck, lint, a production Webpack build and independent schema/CSV/headline-provenance checks. All 24,000 modeled pairs reproduce export labels. Publication rejects malformed records and forged eligibility. Content-addressed snapshots and `submission/audit_log.json` record input/output hashes; full offline replay is not established. The 37-case AI-authored reference set has 31/33 correct definite answers, three correctly indeterminate cases and one unmatched rule; it is not independent or an official score. Repeat release checks after integration and verify the public demo.
